Suggested Workflow

A comprehensive flow of how a developer would leverage this template. For the basics, see the project GETTING_STARTED.MD file.

Super Flow

  • Besides the normal GETTING_STARTED flow - make all the changes you want to match your brand and theming. see the CUSTOM-TEMES.md file in the skills directory
  • Replace the starter component with your own and update routing in frontend/src/app/app.routes.ts
  • Remove the router links in the side nave to demo and SuggestedFlow in frontend/src/app/app.routes.ts
  • Add any components, side navs, links, etc. you want all your apps to share at the outset
  • Update the logo and app icon
    Logo frontend/public/logo.png
    Favicon frontend/public/favicon.ico
  • Add your own specific design rules (like using certain components for tables or charts, toasts, etc).
  • Build skill files for these design rules in the skills folder.
  • Push this up as your own starting template to your repository.
  • Clone from your branded repo version so future apps you create are all based on the same patterns and design.

🤖 Want your coding agent to handle this for you?

You don't have to perform these steps manually. This template is equipped with a dedicated skill guide at skills/INITIAL-FLOW.md designed specifically to orchestrate this setup.

How to use: Point your AI coding assistant (like Cursor, Windsurf, Copilot, or Cline) to the skills/INITIAL-FLOW.md file in your workspace, and prompt it:
"Read skills/INITIAL-FLOW.md and execute the initial branding and cleanup tasks."

The agent will automatically process the branding configuration, configure your clean routes in frontend/src/app/app.routes.ts, remove demo templates, and set up the foundation for your new workspace layout.
